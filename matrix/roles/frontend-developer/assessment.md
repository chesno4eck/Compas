# Рекомендации по оценке: Frontend-разработчик

Навык SFIA общий. Ниже — что проверять **в контексте этой роли**. Если навыка нет в списке — используйте универсальный текст SFIA.

## PROG — Программирование / разработка ПО

### Уровень 2

**Проверять:**

- Пишет простые UI-компоненты/страницы на стеке команды (JS/TS + фреймворк)
- Следует code style, линтерам; базовая работа с Git и PR
- Не хардкодит секреты; понимает базовые XSS-риски (не вставляет сырой HTML без нужды)

**Артефакты:**

- PR с простым компонентом
- Скрин UI
- Прохождение линтера/CI

### Уровень 3

**Проверять:**

- Самостоятельно закрывает фичу: UI + данные (API/state) + ошибки/loading
- Типизация (TS), границы компонентов, базольные тесты где принято
- Участвует в review; предлагает практичные фиксы проблем

**Артефакты:**

- PR фичи со state/API
- Unit/component тест
- Ревью с замечаниями по качеству

### Уровень 4

**Проверять:**

- Реализует сложные клиентские модули: сложный state, микрофронт/пакеты, интеграции SDK
- Влияет на выбор библиотек, bundler/CI практик, security (CSP, зависимость supply-chain)
- Ведёт ревью; рефакторит legacy UI без регрессий

**Артефакты:**

- ADR по фронтенд-архитектуре
- Сложный PR + ревью коллег
- Рефакторинг модуля

### Уровень 5

**Проверять:**

- Отвечает за construction frontend-стрима: стандарты кода, качество поставки
- Адаптирует методы (SSR/SPA/острова, монорепо) под продукт
- Вносит вклад в орг. гайдлайны фронтенда

**Артефакты:**

- Стандарты фронтенда
- План тех. инициативы
- Метрики качества (бандл, ошибки)

## SWDN — Проектирование ПО

### Уровень 2

**Проверять:**

- Описывает простой компонент: props/state, ответственность, события

**Артефакты:**

- Короткий design note / Storybook story

### Уровень 3

**Проверять:**

- Проектирует составные UI-модули и контракты данных
- Учитывает accessibility и performance на уровне структуры компонентов

**Артефакты:**

- Схема компонент/потока данных
- Публичный API компонента

### Уровень 4

**Проверять:**

- Проектирует сложные клиентские подсистемы (дизайн-система, routing, data layer)
- Сравнивает альтернативы (состояние, кэш, границы бандла)

**Артефакты:**

- ADR
- Прототип спорного UX/техрешения

### Уровень 5

**Проверять:**

- Задаёт frontend design standards для продукта/направления

**Артефакты:**

- Архитектурные принципы фронта
- Ревью крупных дизайн-решений

## SINT — Интеграция систем и сборка

### Уровень 2

**Проверять:**

- Собирает проект (npm/pnpm/yarn), гоняет локальные тесты/lint по инструкции

**Артефакты:**

- CI green на своём PR

### Уровень 3

**Проверять:**

- Настраивает env/сборку фичи, feature flags, базовые preview-деплои
- Чинит типовые поломки pipeline

**Артефакты:**

- PR с CI/env правкой
- Preview URL фичи

### Уровень 4

**Проверять:**

- Улучшает integration/build: split bundles, caching CI, контракты с backend

**Артефакты:**

- Ускорение CI/бандла с метрикой
- План интеграции

### Уровень 5

**Проверять:**

- Развивает build/deploy capabilities фронтенд-направления

**Артефакты:**

- Стандарт pipeline
- Выбор bundler/hosting подхода

## TEST — Функциональное тестирование

### Уровень 1

**Проверять:**

- Прогоняет готовый чеклист UI под mentorship

**Артефакты:**

- Отмеченный чеклист

### Уровень 2

**Проверять:**

- Составляет чеклист к своей UI-фиче (браузеры/адаптив по договорённости)
- Оформляет баги с шагами и окружением

**Артефакты:**

- Чеклист к PR
- Баг-репорт

## HCEV — Проектирование пользовательского опыта

### Уровень 2

**Проверять:**

- Верстает по макету/дизайн-системе; соблюдает spacing/типографику

**Артефакты:**

- PR + сравнение с макетом

### Уровень 3

**Проверять:**

- Делает сложные интерфейсы, адаптив, состояния компонентов
- Итеративно согласует с дизайном; применяет brand/visual guidelines

**Артефакты:**

- Сложный UI PR
- Storybook/пример состояний

### Уровень 4

**Проверять:**

- Выбирает interaction-паттерны, прототипирует UX-спорные места
- Влияет на дизайн-систему и паттерны продукта

**Артефакты:**

- Вклад в DS
- Прототип + обоснование trade-off

## ACIN — Доступность и инклюзивность

### Уровень 2

**Проверять:**

- Прогоняет базовые a11y-проверки (клавиатура, контраст) по чеклисту

**Артефакты:**

- Заметки прогона axe/Lighthouse a11y

### Уровень 3

**Проверять:**

- Делает семантическую вёрстку, роли/имена, фокус-менеджмент на своих экранах
- Чинит типовые WCAG-замечания

**Артефакты:**

- PR с a11y-фиксами
- Отчёт axe/ручной keyboard-прогон

### Уровень 4

**Проверять:**

- Влияет на доступность дизайна фичи; планирует a11y-тесты
- Оценивает риски compliance

**Артефакты:**

- A11y review фичи
- Чеклист/стандарт для команды

## NFTS — Нефункциональное тестирование

### Уровень 2

**Проверять:**

- Смотрит Web Vitals/Lighthouse на своей странице; ловит очевидный jank

**Артефакты:**

- Lighthouse/Web Vitals снимок
- Фикс performance в PR

### Уровень 3

**Проверять:**

- Планирует performance-проверки для рискованных UI (бандл, runtime)
- Понимает базовые метрики ошибок клиента

**Артефакты:**

- Чеклист NFT к фиче
- Сравнение бандла до/после

## USEV — Оценка пользовательского опыта

### Уровень 2

**Проверять:**

- Собирает feedback по прототипу/UI у коллег или пользователей по шаблону

**Артефакты:**

- Заметки feedback

### Уровень 3

**Проверять:**

- Проводит лёгкую usability-проверку компонента; фиксирует findings

**Артефакты:**

- Короткий evaluation report

## METL — Методы и инструменты

### Уровень 2

**Проверять:**

- Работает в IDE/Git/CI по гайдам; использует Storybook/линтеры команды

**Артефакты:**

- PR по шаблону

### Уровень 3

**Проверять:**

- Конфигурирует eslint/prettier/test runner в зоне фичи; обновляет docs

**Артефакты:**

- PR с tool-config

### Уровень 4

**Проверять:**

- Рекомендует инструменты фронта; помогает с adoption

**Артефакты:**

- Гайд по tool
- Внедрение шаблона

### Уровень 5

**Проверять:**

- Выбирает и оценивает toolchain направления

**Артефакты:**

- Decision record по toolstack

## RELM — Управление релизами

### Уровень 2

**Проверять:**

- По чеклисту готовит релиз фронта (notes, проверка env)

**Артефакты:**

- Release checklist

### Уровень 3

**Проверять:**

- Проводит типовой деплой/релиз фичи по процессу команды

**Артефакты:**

- Статус раскатки / changelog

### Уровень 4

**Проверять:**

- Планирует релизы с feature flags, миграциями, откатом

**Артефакты:**

- План релиза
- Post-release review
