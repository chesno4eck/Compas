# Рекомендации по оценке: Frontend-разработчик

Навык SFIA общий. Ниже — что проверять **в контексте этой роли**. Если навыка нет в списке — используйте универсальный текст SFIA.

## PROG — Программирование / разработка ПО

### Уровень 2

**Проверять:**

- Пишет простые экраны и утилиты на JavaScript/TypeScript (типы, коллекции, функции) по задаче
- Использует React на типовых задачах под менторством: компоненты, базовые хуки
- Не хранит секреты в коде; базово соблюдает privacy-ограничения и не вставляет сырой HTML без нужды
- Перед сдачей сам просматривает свой PR, правит замечания

**Артефакты:**

- PR с простой фичей или багфиксом
- Скрин/запись экрана по задаче
- Простой unit-тест по образцу команды

### Уровень 3

**Проверять:**

- Самостоятельно закрывает фичу целиком: данные (клиент или сервер), состояние UI, ошибки и загрузка
- Уверенно применяет TypeScript (дженерики, типизация API-контрактов) и React 19: хуки, Suspense
- Следует архитектурным соглашениям команды (App Router: клиентские и серверные компоненты, layouts, где SSR/CSR/ISR)
- Пишет и дополняет unit-тесты на новую логику; участвует в ревью кода; понимает HTTP/HTTPS и когда уместен WebSocket

**Артефакты:**

- PR фичи с загрузкой данных и UI-состояниями
- Ревью с содержательными комментариями
- Разбор бага с корневой причиной в тикете

### Уровень 4

**Проверять:**

- Реализует сложные модули и интеграции: Server Actions, route handlers, Cache Components (`use cache`, cacheLife/cacheTag, ревалидация по тегам), WebSocket, межмодульное взаимодействие
- Влияет на выбор подходов, зависимостей и практик безопасности в команде (TLS, HTTPS, сторонние пакеты); владеет utility- и conditional-типами TypeScript
- Ведёт ревью коллег; проводит рефакторинг устаревшего кода с сохранением поведения
- Оценивает риски релиза (регрессии, миграции, кэш, совместимость браузеров); понимает модель OSI достаточно, чтобы рассуждать о слое проблемы

**Артефакты:**

- ADR или RFC по кэшу, модульности или архитектуре фичи
- Серия ревью с планкой качества
- Рефакторинг с метриками / разбор инцидента

### Уровень 5

**Проверять:**

- Берёт тех. ответственность за фронтенд-стрим: от требований до поставки и оценки качества
- Планирует разработку: выбирает SSR/CSR/ISR, границы клиент/сервер, стратегию кэша и feature-флаги — под задачу и контекст
- Контролирует стандарты команды, включая privacy, TLS и безопасность сторонних зависимостей
- Вносит вклад в руководства по фронтенд-разработке сообщества или организации

**Артефакты:**

- Принятые стандарты и гайды
- План тех. инициативы с метриками успеха
- Менторство с измеримым ростом людей

## SWDN — Проектирование ПО

### Уровень 2

**Проверять:**

- Описывает простой экран или компонент: ответственность, входы и выходы, базовый поток данных
- Применяет паттерны команды (например, простой клиентский компонент React) под контролем

**Артефакты:**

- Схема или короткая заметка по дизайну к задаче
- Диаграмма потока данных экрана

### Уровень 3

**Проверять:**

- Проектирует умеренно сложный модуль: слои, интерфейсы, состояния, ошибки; типизирует контракты API
- Учитывает границы клиентских и серверных компонентов, layouts App Router, базовые нефункциональные требования

**Артефакты:**

- Проектный документ модуля
- Интерфейсы/типы и границы модуля в PR

### Уровень 4

**Проверять:**

- Проектирует сложные модули и интеграции с компромиссами (модульность, тестируемость, производительность, что можно и нельзя кэшировать)
- Ведёт ревью дизайнов коллег; прототипирует спорные решения

**Артефакты:**

- ADR с разбором альтернатив
- Ревью архитектурного предложения

### Уровень 5

**Проверять:**

- Задаёт подход к проектированию и архитектуре для крупной зоны веб-продукта
- Балансирует качество, безопасность и поддерживаемость; влияет на стандарты проектирования

**Артефакты:**

- Архитектурные принципы стрима
- Анализ влияния крупного изменения

## SINT — Интеграция систем и сборка

### Уровень 2

**Проверять:**

- Собирает проект (npm/pnpm/yarn) или по CI-инструкции команды, прогоняет заданные проверки
- Фиксирует падения сборки и тестов с воспроизведением

**Артефакты:**

- Лог успешной или упавшей сборки
- Скрин задачи CI

### Уровень 3

**Проверять:**

- Настраивает зависимости модуля, понимает структуру Next.js (app, layouts, route handlers, env)
- Чинит типовые поломки CI; готовит превью-сборку или внутреннюю раздачу

**Артефакты:**

- PR с правкой package.json или конфига CI
- Успешный превью-деплой

### Уровень 4

**Проверять:**

- Проектирует сложные интеграционные сборки, модульную сборку, ускорение CI
- Согласует интеграцию с платформенной или бэкенд-командой (контракты API, кэш, ревалидация)

**Артефакты:**

- Ускорение пайплайна с метрикой времени
- План интеграции крупной фичи

### Уровень 5

**Проверять:**

- Развивает CI/CD и практики интеграции фронтенд-направления
- Выбирает инструменты сборки и дистрибуции, задаёт стандарты

**Артефакты:**

- Стандарт CI для фронтенда
- Внедрение новых инструментов сборки

## TEST — Функциональное тестирование

### Уровень 1

**Проверять:**

- Прогоняет готовый чеклист по своей задаче под наставничеством

**Артефакты:**

- Отмеченный чеклист в тикете

### Уровень 2

**Проверять:**

- Составляет короткий чеклист к своей фиче (основной сценарий и базовые негативные)
- Заводит баги с шагами, окружением (браузер/OS), ожидаемым и фактическим результатом

**Артефакты:**

- Чеклист к PR
- Заведённый баг с полным описанием

## HCEV — Проектирование пользовательского опыта

### Уровень 2

**Проверять:**

- Верстает простые экраны по макету (React), соблюдает отступы и компоненты дизайн-системы

**Артефакты:**

- PR с UI по макету
- Сравнение с дизайном

### Уровень 3

**Проверять:**

- Собирает сложные экраны, кастомные компоненты, стандартную навигацию App Router
- Согласует реализуемость с дизайнером; учитывает адаптив и тёмную тему, где принято

**Артефакты:**

- Переиспользуемый UI-компонент
- Комментарии и итерации с дизайном

### Уровень 4

**Проверять:**

- Проектирует UI со сложным взаимодействием: кастомные переходы, сложные состояния, Suspense-границы
- Влияет на паттерны UI в команде и дизайн-системе

**Артефакты:**

- Компонент дизайн-системы
- Кастомный переход или сложная анимация

## ACIN — Доступность и инклюзивность

### Уровень 2

**Проверять:**

- Прогоняет базовые проверки клавиатуры, скринридера и контраста по чеклисту

**Артефакты:**

- Заметки прогона доступности

### Уровень 3

**Проверять:**

- Делает семантическую вёрстку, роли и имена, управление фокусом на своих экранах
- Проверяет контраст и крупный текст на типовых сценариях

**Артефакты:**

- PR с правками доступности
- Чеклист доступности по фиче

## NFTS — Нефункциональное тестирование

### Уровень 2

**Проверять:**

- Смотрит Lighthouse, React Profiler или Network на явные проблемы своей фичи
- Ловит очевидные подтормаживания, лишние перерисовки и тяжёлые клиентские бандлы

**Артефакты:**

- Скрин или заметка прогона
- Фикс подтормаживаний или размера бандла в PR

### Уровень 3

**Проверять:**

- Планирует простые проверки производительности и стабильности для рискованных изменений (кэш, SSR, водопады запросов)
- Умеет интерпретировать базовые метрики ошибок клиента и Web Vitals

**Артефакты:**

- Короткий чеклист нефункциональных проверок к релизу фичи
- Разбор деградации производительности

## METL — Методы и инструменты

### Уровень 2

**Проверять:**

- Работает в IDE и Git по гайдам команды; обновляет README и заметки по просьбе

**Артефакты:**

- PR по шаблону команды

### Уровень 3

**Проверять:**

- Настраивает линтеры, форматтеры и TypeScript в своём модуле; чинит типовые проблемы с инструментами

**Артефакты:**

- PR с конфигом ESLint/Prettier/tsconfig и т.п.

### Уровень 4

**Проверять:**

- Рекомендует и внедряет инструменты фронтенд-команды; пишет короткие гайды

**Артефакты:**

- Гайд по инструменту
- Внедрение нового шаблона или генератора

### Уровень 5

**Проверять:**

- Выбирает набор инструментов для направления; оценивает их пользу

**Артефакты:**

- Решение о выборе инструмента с критериями
- Политика использования AI/IDE в команде

## RELM — Управление релизами

### Уровень 2

**Проверять:**

- По чеклисту готовит материалы релиза (заметки, сборка) под контролем

**Артефакты:**

- Заполненный чеклист релиза

### Уровень 3

**Проверять:**

- Проводит типовой релиз фичи в превью и прод по процессу команды
- Ловит блокеры релиза

**Артефакты:**

- Релиз-ноты и статус раскатки

### Уровень 4

**Проверять:**

- Планирует релиз с зависимостями, поэтапной раскаткой, feature-флагами и ревалидацией кэша

**Артефакты:**

- План релиза
- Разбор после релиза
