# BUSA — Анализ бизнес-ситуации

> SFIA 9: [Business situation analysis](https://sfia-online.org/en/sfia-9/skills/business-situation-analysis)

Исследование бизнес-контекста: проблемы, возможности, root cause analysis, рекомендации для изменений.

## Уровни

### Уровень 2 — Assist

Помогает исследовать бизнес-ситуации, выявлять проблемы и возможности. Собирает и организует данные для рекомендаций.

### Уровень 3 — Apply

Исследует straightforward ситуации, анализирует проблемы и возможности. Следует стандартам investigation. Взаимодействует со стейкхолдерами под руководством.

### Уровень 4 — Enable

Исследует ситуации со сложностью и неоднозначностью. Holistic view, root cause analysis. Выбирает подход и техники. Взаимодействует с operational stakeholders.

### Уровень 5 — Ensure, advise

Планирует и ведёт analysis при значительной ambiguity. Advises по подходам. Holistic view широкого спектра проблем. Согласует conclusions с management-level stakeholders.

### Уровень 6 — Initiate, influence

Инициирует analysis при extensive ambiguity и org impact. Продвигает holistic analysis до change programmes. Engages executive level. Определяет org policies для analysis.
