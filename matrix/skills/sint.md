# SINT — Интеграция систем и сборка

> SFIA 9: [Systems integration and build](https://sfia-online.org/en/sfia-9/skills/systems-integration-and-build)

Интеграция компонентов, CI/сборки, окружения и интеграционное тестирование — включая automation и continuous integration.

## Уровни

### Уровень 2 — Assist

Собирает builds из компонентов с помощью согласованных automation-инструментов. Выполняет интеграционные тесты по спецификации, фиксирует отказы, сообщает о рисках.

### Уровень 3 — Apply

Определяет модули, зависимости и build definition. Принимает компоненты по критериям, настраивает окружение, проводит интеграционные тесты, диагностирует дефекты, готовит отчёты.

### Уровень 4 — Enable

Обеспечивает конфигурацию компонентов для системного тестирования. Согласует integration plans, проектирует сложные builds, улучшает процессы и инструменты интеграции.

### Уровень 5 — Ensure, advise

Планирует развитие орг. capabilities интеграции и CI/automation. Выбирает инструменты и процессы, даёт authoritative advice, мониторит стандарты, вносит вклад в политики.

### Уровень 6 — Initiate, influence

Возглавляет развитие орг. capabilities systems integration and build. Задаёт политики и стандарты, обеспечивает ресурсы и adoption.
